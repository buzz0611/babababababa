# 🏀 バスケットボール Webアプリ集

ブラウザで開くだけで動く、バスケットボールのための2つのWebアプリです。ビルドやサーバーは不要です。

| ファイル | アプリ |
|---|---|
| `index.html` | ポジション解説・フォーメーション再生 |
| `stats.html` | 試合動画を見ながらのスタッツ記録・可視化 |

```bash
open index.html        # macOS
open stats.html
# または任意のブラウザにドラッグ&ドロップ
```

## スタッツ記録・可視化アプリ（stats.html）

試合動画をブラウザで再生しながら、選手ごとのプレーをワンタップで記録し、成績をグラフで可視化します。動画ファイルはブラウザ内で再生されるだけで、どこにもアップロードされません。

### 記録できるスタッツ

- 得点: 2P / 3P / フリースロー（成功・失敗それぞれ）
- アシスト / リバウンド / スティール / ブロック / ターンオーバー / ファウル

### 主な機能

- **動画プレーヤー**: ローカルの動画ファイルを読み込み、速度変更（0.25x〜2x）・5秒/10秒スキップ・キーボード操作（スペース/←→）に対応
- **ワンタップ記録**: 選手を選んでプレーボタンを押すと、動画の再生時刻つきで記録。取り消し・削除も可能
- **プレーログ**: 記録一覧から時刻をタップすると、動画がそのプレーの3秒前にジャンプ
- **ボックススコア**: PTS / 2P / 3P / FT / FG% / AST / REB / STL / BLK / TO / F を選手別+チーム合計で表示
- **グラフ**:
  - 選手別の得点内訳（2P / 3P / FT のスタック棒グラフ）
  - スタッツ比較（アシスト・リバウンド・スティール・ブロックなどを切り替え）
  - チーム得点の推移（動画時間軸のステップ折れ線、ホバーでプレー詳細）
- **シュートの自動検出（ベータ）**: 固定カメラ向けの半自動機能。動画上でリングとネット全体をドラッグで囲むと、シュートらしき瞬間を**候補**として自動抽出。感度スライダーで調整でき、各候補は再生して確認後、選手と結果（2P/3P/FTの成功・失敗）を選んで確定します（囲んだリング位置はブラウザに保存され、次回以降も使い回せます）
- **CSVエクスポート**: ボックススコアとプレーログをCSV保存（Excel対応）
- **自動保存**: 記録はブラウザのlocalStorageに自動保存（動画は再開時に再選択）

### シュートの自動検出について

「見ながらタップ」を基本にしつつ、シュートの見逃し・巻き戻しの手間を減らすための補助機能です。**固定カメラ**であることを利用し、囲んだリング枠を上35%（リング上）と下65%（ネット）の2ゾーンに分けて、ネイティブ解像度で**「リング上→ネット」の順に短い動きが通過した瞬間**だけをシュート候補として挙げます。0.6秒以上続く動きは「人の横切り」として自動で除外します。

実際の体育館の試合映像（1台固定・コート全体、リングが画面上で幅約35pxしかない条件）で検証し、**クリップ内のシュート3本（成功2・リムアウト1）をすべて検出、人の横切りによる誤検出は0件**でした。

- 全自動ではなく **「シュート候補は自動・選手と結果は人が確定」** の半自動方式です。映像によって誤検出・見逃しは出るため、感度を調整しながら使ってください。
- 成功だけでなく**リムアウトの失敗も拾える**ので、シュート試投（FGA）の記録にも役立ちます。
- カメラが手持ち・パンありだと使えません。**三脚などで固定**した映像が前提です。
- 解析は動画を2倍速で再生しながら行うため、おおよそ動画の半分の時間がかかります。
- アシスト・スティール・ブロックなど「複数選手の意図」が関わるプレーは自動検出の対象外で、従来どおりワンタップで記録します。

## ポジション解説アプリ（index.html）

バスケットボールの5つのポジション（PG / SG / SF / PF / C）を、コート図を使ってインタラクティブに学べます。

### ポジション解説モード

- **コート図のマーカー**をクリック（またはボタンをタップ）してポジションを選択
- 各ポジションの解説を表示:
  - 役割・特徴の説明
  - 求められる能力のグラフ表示
  - 代表的な選手（NBA・日本人選手）
  - 上達のヒント

### フォーメーションモード

- 代表的な連携プレーを、選手とボールがコート上を動くアニメーションで再生:
  - 基本プレー: ピック&ロール / ギブ&ゴー / ドライブ&キックアウト
  - UCLA+Zoom練習（G・F・Cの3人組ドリル）:
    1. Gカッティング
    2. Cダイブ
    3. Fバックドア
    4. Fドライブ
    5. UCLA→Fダウンスクリーン+ハンドオフ
    6. Cフラッシュ→Gダウンスクリーン+ハンドオフ
- 再生・一時停止・リセット・速度切替（ゆっくり / ふつう）
- 進行中のステップを「プレーの流れ」リストでハイライト表示

### 共通

- レスポンシブ対応（スマホ・タブレット・PC）
- ダークモード対応（OS設定に自動追従）
- キーボード操作対応（Tabで選択、Enterで決定）

## 技術

- 依存ライブラリなしの単一HTMLファイル（HTML / CSS / Vanilla JS）
- コート図はSVGで描画
