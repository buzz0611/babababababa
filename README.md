# 🏀 バスケットボール ポジション解説アプリ

バスケットボールの5つのポジション（PG / SG / SF / PF / C）を、コート図を使ってインタラクティブに学べるWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動作します。ビルドやサーバーは不要です。

```bash
open index.html        # macOS
# または任意のブラウザにドラッグ&ドロップ
```

## 機能

### ポジション解説モード

- **コート図のマーカー**をクリック（またはボタンをタップ）してポジションを選択
- 各ポジションの解説を表示:
  - 役割・特徴の説明
  - 求められる能力のグラフ表示
  - 代表的な選手（NBA・日本人選手）
  - 上達のヒント

### フォーメーションモード

- 代表的な連携プレーを、選手とボールがコート上を動くアニメーションで再生:
  - ピック&ロール
  - ギブ&ゴー
  - ドライブ&キックアウト
- 再生・一時停止・リセット・速度切替（ゆっくり / ふつう）
- 進行中のステップを「プレーの流れ」リストでハイライト表示

### 共通

- レスポンシブ対応（スマホ・タブレット・PC）
- ダークモード対応（OS設定に自動追従）
- キーボード操作対応（Tabで選択、Enterで決定）

## 技術

- 依存ライブラリなしの単一HTMLファイル（HTML / CSS / Vanilla JS）
- コート図はSVGで描画
