# 📋 産業廃棄物マニフェスト帳簿（プロトタイプ）

排出事業者向けに、紙マニフェストの交付・返送状況を管理する Web アプリです。
`index.html` をブラウザで開くだけで動作します（依存ライブラリなし・データはブラウザ内に保存）。

## 機能

- 返送票（B2・D・E票）の期限管理とアラート（B2/D: 90日・特管60日、E: 180日）
- 措置内容等報告書の提出期限（返送期限経過後30日）表示
- マニフェスト台帳（検索・絞り込み・CSV出力・保存期限5年の表示）
- 産業廃棄物管理票交付等状況報告書（様式第三号）の年度・事業場別集計
- 委託先の業許可・委託契約の期限アラート
- JSON バックアップ／復元、サンプルデータ

※ 法令の要点を簡略化しています。運用前に最新の法令・自治体の指導内容を確認してください。
